# Workspace

기존 ARTEX 문서와 구분해 우리가 작성하는 문서와 자료를 모으는 공간이다.
기존 ARTEX 문서는 저장소의 `docs/`에서 관리한다.

## 현재 자료

- [스크린샷 기반 화면 안내서](guides/artex-screen-guide.html): 페이지·탭·팝업 51개와 번호별 구성요소 234개를 설명한다. HTML 파일을 브라우저에서 직접 열면 된다.

안내서는 현재 UI를 예시 데이터로 촬영한 자료이며, 실제 인증이나 분석 실행을 검증한 결과는 아니다. 이미지가 HTML에 내장되어 별도 이미지 폴더 없이 사용할 수 있다.

## 자료 추가 기준

필요한 자료가 생길 때 다음 디렉터리를 추가한다.

- `guides/`: 화면·사용 흐름 안내
- `plans/`: 기획·설계·작업 계획
- `research/`: 조사·실험 정리
- `notes/`: 회의·아이디어·메모
- `presentations/`: 발표 자료

현재는 화면 안내서만 포함한다. 기존 발표·실험·계획 자료는 이번 정리와 커밋에 포함하지 않는다. `workspace/`라는 이름은 접근 제한을 의미하지 않으며, 비공개 자료와 자격증명은 이 목차나 안내서에 넣지 않는다.
