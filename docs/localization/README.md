# 내부 코드와 프롬프트 한글화

2026-10-27 승인 범위: 중국어로 작성된 내부 프롬프트, 도구 설명, 기본 문구, 오류·로그, 주석과 내장 스킬 문서를 한국어로 번역한다. `localization/korean`에서 작업하고 `dev` 대상 PR로 검토한다.

## 변경과 호환성

- 에이전트·플래너·검토·추가 질문·승인 판단 프롬프트의 권한, 중단 조건, 출력 형식과 치환 변수는 유지한다.
- 승인 판단의 세 부분 설명은 한국어로 출력하며, 파서는 기존 중국어 형식도 받아들인다. 혼합 형식, 빈 항목, 허용되지 않은 결정 값은 기존과 같이 거부한다.
- 한국어 로그가 기존 로그와 동일한 심각도로 분류되도록 키워드와 회귀 검사를 추가했다. 변경된 로그 형식 167개의 분류를 대조했다.
- API 키, 도구 이름, 저장 형식, SQL 식별자와 탐지 시그니처는 유지한다.
- 기존 설치의 사용자 설정·저장된 프롬프트·대화·증거는 일괄 치환하지 않는다. 새 기본값은 한국어지만 이미 저장된 문구는 원래 언어로 남을 수 있다.
- 이 변경은 소스 한글화 PR이다. 실행 중인 데스크톱 앱에 자동 반영되지는 않는다.

## 의도적으로 보존한 원문

`retained-han.json`에 113개 파일의 보존 사유를 기록했다. 지원 중인 중국어·일본어 로캘과 원어 문서는 파일 단위로 허용한다. 증거 원문, 다국어 테스트, 과거 형식 파서, 언어 식별자, 탐지용 고정 접두어 등은 정확한 줄의 SHA-256과 발생 횟수로 관리한다.

```sh
python3 scripts/audit-korean-localization.py --check
```

검사는 Git이 추적하거나 무시하지 않는 새 텍스트 파일을 대상으로 한다. 바이너리, 심볼릭 링크, 무시된 빌드 산출물과 외부 DB는 대상이 아니다. 분류되지 않은 문구나 변경된 보존 줄은 실패하며, 원문 내용은 출력하지 않는다. 정상적인 로캘 편집 외의 예외 변경은 사유를 확인한 후 목록에 반영한다.

## 검증 결과

- `go test -json -count=1 ./...`: 성공. 테스트 이벤트 기준 919개 통과, 273개 건너뜀. DB 연결이 필요한 검사는 아래의 별도 실행으로 확인했다.
- 새 임시 PostgreSQL의 패키지별 격리 DB에서 `agent`, `db`, `server` 재실행: 각각 91개, 259개, 429개 통과. 실제 외부 모델 연결이 필요한 `TestLiveContextReview` 1개는 실행하지 않았다. 사용자 DB는 사용하지 않았다.
- 정적 내보내기: `NEXT_EXPORT=1 next build --webpack` 통과, 생성 HTML의 한자 누출 검사 통과. 기본 Turbopack 빌드는 격리 폴더 밖의 `node_modules` 심볼릭 링크를 거부하므로 Webpack으로 검증했다.
- `web`: Vitest 14개 파일의 80개 테스트 통과, TypeScript 타입 검사 통과.
- `go build ./...`, `go vet ./...`, 로캘 키 정합성 검사와 문서 내부 링크 검사 통과.
- Biome은 기준 커밋에서도 오류 62개가 재현된다. 이번 번역으로 추가된 포맷 오류 1개는 정리했으며, 기존 린트 오류는 이 작업에서 수정하지 않는다. 파일·규칙·진단 내용별 비교에서 추가·제거 진단은 0개다.
- 탐지 지문 검사, 잔여 Han 검사, `git diff --check` 통과.
- 병렬 번역 후 프롬프트의 정책 의미, 템플릿·printf 변수, 코드 구조와 테스트 조건을 교차 검토했다.

소스·회귀 테스트 통과는 실제 모델의 판단 품질이나 토큰 사용량이 원문과 동일함을 보장하지 않는다. 실제 모델 평가와 데스크톱 재패키징은 이 PR의 검증 범위에 포함하지 않는다.
